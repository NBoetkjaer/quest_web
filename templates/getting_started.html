Installation af Python og VS Code editoren

Installation af Python

Inden du kan kommme i gang med at løse de forskellige opgaver, skal du sørge for at Python er installeret på din PC. Hvis du benytter Windows OS er det letteste at benytte Microsoft Store.

  1. Åben 'Microsoft Store' (Find Store-app'en ved at Trykke på windows tasten og skrive 'store').
  2. Søg efter Python og installer den nyeste du kan finde f.eks. version 3.13

Installation af Visual Studio Code

Visual Studio Code (VS Code) editoren er en god og hurtig editor til at skrive din kode i. Den kan også installeres ved at benytte Microsoft Store app'en.

  1. Åben 'Microsoft Store' app'en igen
  2. Søg efter Visual Studio Code og installer denne

Opsætning af Visual Studio Code

Visual Studio Code editoren kan benyttes til mange forskellige programmeringssprog. Da vi ønsker at benytte Python skal du installer en Python Extension til VS Code. Denne extension gør det muligt at skrive og debugge den Python kode, som du skal til at skrive.

Opsætning af Python

Da de forskellige programmeringsopgaver skal hentes fra en webserver, benytter vi en Python hjælpe-pakke til at kommunikere med serveren. Den pakke vi skal benytte hedder 'requests'.
For at installere denne pakke skal du åbne en terminal / commando-prompt og skrive følgende:

python -m pip install requests

Test om det virker ...

  1. Start VS code
  2. opret en ny fil og giv den en navn der ender på '.py' (f.eks. test.py)
  3. Skriv følgende kode i din nye Python fil:

    4. print('Hejsa')

  4. Tryk på <F5> for at køre og debugge dit Python program.

Hvis dit program skrev 'Hejsa' i VS Code terminal vinduet - Så virker din opsætning og du er klar til den første opgave
